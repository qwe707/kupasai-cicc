\### 🛠️ 压缩 WSL2 Ubuntu 虚拟磁盘 (释放 C 盘空间)



\*\*第一步：在 Ubuntu 中清理 Docker 垃圾（关键前提）\*\*

在压缩磁盘之前，必须先在 Ubuntu 里把该删的删掉，否则压缩了也没用。

打开你的 Ubuntu 终端，执行：

```bash

# 清理无用镜像、容器和缓存
sudo docker system prune -a --volumes

```


\*\*第二步：彻底关闭 WSL\*\*

打开 Windows 的 \*\*PowerShell\*\*（最好是以管理员身份运行），输入以下命令并回车，强制关闭所有正在运行的 Linux 子系统：

```powershell

wsl --shutdown

```


\*\*第三步：找到你的 Ubuntu `.vhdx` 文件路径\*\*



\*\*第四步：使用 Diskpart 进行压缩\*\*

回到刚才的 PowerShell 窗口，依次输入以下命令：



1\. 启动磁盘管理工具：

```powershell

diskpart

```

2\. 在弹出的 `DISKPART>` 提示符后，选择你的虚拟磁盘（\*\*把下面的路径替换成你刚才找到的真实路径\*\*，注意保留双引号）：

```text

select vdisk file="D:\WSL\Ubuntu-24.04\ext4.vhdx"

```

3\. 执行压缩命令：

```text

compact vdisk

```

&#x20;  \*此时系统会开始压缩，等待进度条跑完。\*

4\. 退出工具：

```text

exit

```
